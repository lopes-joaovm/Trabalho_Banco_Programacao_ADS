# Sistema Bancário - INF101

Trabalho desenvolvido para a disciplina de Programação, com o objetivo de criar um sistema bancário simples utilizando C++.

O programa permite realizar o cadastro e o gerenciamento de contas bancárias através de um menu no terminal.

## Funcionalidades

O sistema possui as seguintes opções:

- Cadastrar uma conta bancária
- Consultar os dados de uma conta
- Verificar o saldo
- Alterar o tipo da conta
- Ativar ou desativar uma conta
- Encerrar o programa

## Dados armazenados

Para cada conta são armazenadas as seguintes informações:

- Número da conta
- Nome do cliente
- CPF
- Tipo da conta
- Saldo
- Situação da conta (ativa ou inativa)

O programa permite cadastrar até 5 contas.

## Tipos de conta

O sistema possui dois tipos de conta:

1. Conta Corrente
2. Conta Poupança

## Como executar

O código foi desenvolvido em C++ e pode ser executado em compiladores compatíveis com a linguagem.

Exemplo utilizando o OnlineGDB:

1. Acesse o OnlineGDB.
2. Selecione a linguagem C++.
3. Cole o código do arquivo `main.cpp`.
4. Clique em `Run`.
5. Utilize o menu exibido no terminal.
